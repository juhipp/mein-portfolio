# Portfolio-Website

Persönliche Portfolio-Website von Julia Hipp, Frontend-Entwicklerin aus dem Raum Hamburg.
Umgesetzt mit React 19 und TypeScript, um aktuelle Frontend-Standards in einem eigenen Projekt praktisch anzuwenden.

## Live

[→ juliahipp.de](https://juliahipp.de)

## Tech-Stack

- React 19
- TypeScript
- Vite

## Lokale Installation

```bash
npm install
npm run dev
```

Der Build erfolgt über `npm run build` (TypeScript-Kompilierung + Vite-Build).
